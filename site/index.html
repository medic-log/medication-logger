Medication logger

Track your prescriptions, pill boxes and weekly refills, with reminders for refills, pickups and running out. Your data stays on your device.

Install web app (any device)

Runs in your browser on any phone, tablet or computer, also offline. Your data stays on that device.

How to install
  1. Open the downloaded medication-logger.apk.
  2. If Android asks, allow your browser or file manager to install unknown apps.
  3. Tap Install. To update later, download and install the new version the same way; your data is kept.

How to install the web app
  1. Open the web app with the button above.
  2. Tap Install when your browser offers it. In Safari on iPhone or iPad, tap Share, then Add to Home Screen.
  3. Open it from your home screen or app list. To move your records from the Android app, use Export there and Import in the web app.
